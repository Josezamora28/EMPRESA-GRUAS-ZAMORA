# Grúas y Transportes Zamora

Sitio web corporativo para una empresa de izaje, transporte pesado y maniobras especializadas. Presenta servicios, capacidades operativas, proyectos destacados y canales de contacto.

## Características

- Landing page corporativa responsive.
- Catálogo de servicios de izaje y logística.
- Portafolio con páginas de detalle.
- Presentación de capacidades y seguridad.
- Formulario de contacto y WhatsApp.
- Navegación móvil y animaciones.
- Metadatos descriptivos para buscadores.

## Tecnologías

HTML5 · CSS3 · JavaScript · SVG · Google Fonts

## Ejecutar localmente

```bash
git clone https://github.com/Josezamora28/GRUAS-ZAMORA.git
cd GRUAS-ZAMORA
python -m http.server 8000
```

Abre `http://localhost:8000`.
